# StreakFlow

**Transforme constância em progresso.**

O StreakFlow é uma aplicação web para rastreamento de hábitos pessoais com sistema de streak. O usuário poderá cadastrar hábitos, registrar diariamente as atividades concluídas e acompanhar sua sequência de dias consecutivos.

O projeto está sendo desenvolvido como atividade da disciplina de **Programação Web**.

## Funcionalidades

* Cadastro de hábitos;
* Registro diário de hábitos concluídos;
* Cálculo automático de streak;
* Visualização do progresso;
* Histórico de hábitos;
* Gerenciamento de hábitos;
* Interface responsiva.
